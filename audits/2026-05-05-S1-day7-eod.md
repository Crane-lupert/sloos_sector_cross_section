### `ecsi_construct.py` (Day 7)
- Built per CLAUDE.md §1.6 baseline component #5 (Bidder-Krane-Park 2026.02 E-CSI proxy)
- Methodology: linear regression `DRTSCILM_t = α + β·X_{t-1} + ε`, where X = (UNRATE, T10Y3M, GDPC1 QoQ growth, VIX). E-CSI = fitted value (predictable component).
- F6-distinctness verified: by OLS construction, fitted values are orthogonal to residuals; residuals are exactly our SLOOS shock z_innov. So E-CSI captures the macro-foreseeable component of SLOOS while our shock captures the residual surprise — fully distinct components.
- Regression diagnostics:
  - n_obs = 144 (one row dropped due to GDP NaN at panel edge)
  - **R² = 0.510**, adj R² = 0.496
  - F p-value = 1.0e-20
  - VIX_lag1: β=+1.996, p=1.1e-16 (strongly significant)
  - T10Y3M_lag1: β=-4.099, p=0.008 (significant — flatter curve = more tightening)
  - UNRATE_lag1: β=-2.218, p=0.060 (marginally significant — surprising sign; deserves audit follow-up)
  - GDPC1_log_growth_lag1: β=-257.5, p=0.059 (marginally significant)
  - corr(fitted, residual) = 0.0 (orthogonality verified to 6 decimal places)
- Output: `data/cache/ecsi_2026-05-05.parquet`
- Tests: 4 (synthetic OLS recovery + orthogonality + real snapshot)

### Risks for Day 8-9
1. **L/S portfolio construction**: which sectors to long/short? Options:
   a. Static: long Industrials (+t @ 6m) / short Healthcare (-t @ 6m) — simplest interpretation of Layer A 6m results
   b. Sign-stratified: long Financials on ease-shock 6m / short Healthcare on either-sign 6m
   c. Cross-section: rank all 11 sectors by 6m t-stat, long top-3, short bottom-3
   Decision held to Day 8 implementation; will report per-construction Δ Sharpe.
2. **Cap-weighted vs equal-weighted L/S**: same trade-off as panel construction.
3. **Signal lag**: SLOOS released ~3 weeks after quarter close. We can trade only post-release. Day 8 layer_d will use t0=release_date+1 trading day for entry.
4. **Δ Sharpe calculation**: classical method = Sharpe(strategy) − Sharpe(baseline-replication). Implementation choice: regress strategy returns on baseline factors, alpha-Sharpe = alpha / std(residual) × sqrt(252). Compare to raw Sharpe of strategy.
